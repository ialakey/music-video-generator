# Справочник по командной строке

[English](cli.md) · **Русский**

[← к README](../README.ru.md) · [конфигурация](configuration.ru.md) · [Python API](api.ru.md)

```bash
python -m musicvideo [ПОДКОМАНДА] AUDIO [ОПЦИИ]
```

`AUDIO` — любой файл, который читает ffmpeg: mp3, wav, flac, m4a, ogg, opus
и так далее. Подкоманду можно не писать — всё, что не является известной
подкомандой, считается аргументами `render`, поэтому две строки ниже
равнозначны:

```bash
python -m musicvideo render track.mp3 -i art.jpg
python -m musicvideo track.mp3 -i art.jpg
```

## Подкоманды

| Подкоманда | Что делает |
|------------|------------|
| `render` | Рендерит полное видео. Подкоманда по умолчанию. |
| `still` | Рендерит один кадр в PNG — быстрый способ проверить настройки. |
| `presets` | Печатает названия пресетов с описаниями. |
| `dump-config` | Печатает (или записывает) итоговый конфиг со всеми умолчаниями. |

### `render`

```bash
python -m musicvideo track.mp3 -i art.jpg -p aesthetic -o output/video.mp4
```

Проходит весь конвейер: аудиоэффекты → анализ спектра → рендер кадров →
кодирование через ffmpeg. Прогресс с оценкой оставшегося времени печатается
в stderr (отключается флагом `--quiet` и когда stderr не терминал).

### `still`

```bash
python -m musicvideo still track.mp3 -i art.jpg --at 45 -o output/proba.png
```

Принимает все флаги `render` плюс `--at СЕКУНДЫ` — момент трека, с которого
взять кадр. Без `--at` кадр берётся на 25 % длины трека. Расширение результата
принудительно меняется на `.png`, если это не `.png`/`.jpg`/`.jpeg`.

Звук всё равно обрабатывается и анализируется (визуализатор должен показать
реальный спектр в этот момент), поэтому `still` не мгновенный — но он
пропускает рендер и кодирование тысяч кадров.

### `presets`

```bash
python -m musicvideo presets
```

Аргументов не принимает. Печатает шесть названий пресетов и вид каждого.

### `dump-config`

```bash
python -m musicvideo dump-config track.mp3 -p aesthetic --dump-to my.json
```

Принимает все флаги `render` плюс `--dump-to ПУТЬ` (`-`, значение по
умолчанию, — вывод в stdout). Записывает полностью собранный конфиг — умолчания,
пресет, файл и флаги уже слиты, — чтобы его можно было отредактировать
и вернуть через `-c`. Название и исполнитель на этом шаге тоже подставляются
из тегов файла.

## Опции

Все они работают с `render`, `still` и `dump-config`.

### Вход и выход

| Флаг | Смысл |
|------|-------|
| `AUDIO` | Позиционный. Аудиофайл. Может задаваться и через `audio_file` в конфиге. |
| `-i`, `--image ПУТЬ` | Фон: картинка, папка с картинками или флаг, повторённый несколько раз. |
| `-o`, `--output ПУТЬ` | Куда записать результат. По умолчанию `output/video.mp4`. |
| `-c`, `--config ПУТЬ` | JSON-файл настроек. См. [конфигурацию](configuration.ru.md). |
| `-p`, `--preset ИМЯ` | Один из `aesthetic`, `lofi`, `phonk`, `minimal`, `retro`, `shorts`. |
| `--lang {en,ru}` | Язык интерфейса. См. [Язык](#язык). |

Папка, переданная в `-i`, разворачивается во все лежащие в ней `.jpg`,
`.jpeg`, `.png`, `.webp`, `.bmp`, `.jfif` и `.avif`, отсортированные по имени;
картинки сменяют друг друга кроссфейдом на протяжении ролика. Несуществующий
путь — ошибка, и она возникает до начала долгой работы.

### Текст

| Флаг | Смысл |
|------|-------|
| `--title ТЕКСТ` | Название трека. Иначе — тег файла, иначе — имя файла. |
| `--artist ТЕКСТ` | Исполнитель. Иначе — тег `artist` или `album_artist`. |

### Обложка

| Флаг | Смысл |
|------|-------|
| `--cover ПУТЬ` | Картинка обложки. |
| `--no-cover` | Не рисовать обложку вовсе. |

Без `--cover` обложка ищется в таком порядке: картинка, встроенная в теги
аудиофайла → первая картинка фона. `--no-cover` отменяет этот поиск целиком.

### Визуализатор

| Флаг | Смысл |
|------|-------|
| `--style ИМЯ` | `circle`, `bars`, `mirror`, `wave`, `ring` или `dots`. |
| `--color HEX` | Основной цвет. `#rgb`, `#rgba`, `#rrggbb`, `#rrggbbaa` или имя цвета PIL. |
| `--color2 HEX` | Второй цвет; полосы окрашиваются градиентом от `color` к `color2`. |
| `--no-visualizer` | Не рисовать визуализатор. |
| `--no-progress` | Не рисовать полосу прогресса. |
| `--grain 0..1` | Плёночное зерно. `0` выключает его и заметно уменьшает файл. |

### Звук

| Флаг | Смысл |
|------|-------|
| `--speed X` | `0.85` = slowed, `1.2` = sped up. Высота тона меняется вместе с темпом. |
| `--reverb 0..1` | Количество реверберации. `0` — выключено. |
| `--bass dB` | Усиление низких частот, в децибелах. |
| `--start СЕК` | Пропустить столько секунд исходника. |
| `--length СЕК` | Взять только столько секунд исходника (считается до `--speed`). |

`--start` и `--length` режут *исходник*, поэтому при `--speed 0.85` отрезок
`--length 40` превращается примерно в 47 секунд видео.

### Видео

| Флаг | Смысл |
|------|-------|
| `--size ШxВ` | Разрешение, например `1920x1080` или `1080x1920`. Обе стороны чётные. |
| `--fps N` | Кадров в секунду. |
| `--crf N` | Качество x264; меньше — лучше и крупнее. По умолчанию `21`. |
| `--preview СЕК` | Отрендерить только первые СЕК секунд; звук обрезается по видео. |
| `--workers N` | Число процессов рендера. `1` отключает параллелизм. |
| `--quiet` | Без прогресса и сообщений. |

При `--workers 0` (умолчание) воркеров берётся на один меньше числа ядер,
с поправкой на то, что каждому нужно хотя бы ~40 кадров, — поэтому короткие
превью считаются в меньшем числе процессов, чем полный трек.

## Язык

Интерфейс говорит по-английски и по-русски. Язык выбирается один раз при
старте, в таком порядке:

1. `--lang en` / `--lang ru` в командной строке;
2. переменная окружения `MUSICVIDEO_LANG`;
3. локаль системы (`LC_ALL`, `LC_MESSAGES`, `LANGUAGE`, `LANG`, затем
   собственная локаль Python — распознаются и `ru_RU.UTF-8`, и виндовое
   `Russian_Russia`);
4. английский как запасной вариант.

```bash
python -m musicvideo track.mp3 -i art.jpg --lang ru    # только этот запуск
export MUSICVIDEO_LANG=ru                              # на всю сессию оболочки
```

`--lang` охватывает справку, прогресс, сообщения о ходе работы и ошибки.
Он читается до построения парсера, поэтому `--lang ru --help` сразу печатает
русскую справку. Выбранный язык передаётся процессам-воркерам через окружение,
так что их сообщения не расходятся с основными.

Несколько строк приходят из самого `argparse` и остаются английскими при любой
настройке — слово `error:` и сообщения вида `invalid int value: 'abc'` или
`invalid choice`. Русского перевода для них Python не поставляет.

## Коды возврата

| Код | Смысл |
|-----|-------|
| `0` | Успех. |
| `1` | Ошибка рендера: ffmpeg упал, нет файла, значение вне допустимого диапазона. |
| `2` | Ошибка конфигурации: неизвестное поле, битый JSON, неизвестный пресет. |
| `130` | Прервано по Ctrl+C. |

## Примеры

```bash
# референсный вид прямо из пресета
python -m musicvideo track.mp3 -i art.jpg -p aesthetic

# проверить настройки на одном кадре до долгого рендера
python -m musicvideo still track.mp3 -i art.jpg -p lofi --at 30

# черновик в 720p: небольшой, быстрый, без зерна
python -m musicvideo track.mp3 -i art.jpg --size 1280x720 --fps 24 --grain 0

# 40 секунд припева, красные зеркальные бары
python -m musicvideo track.mp3 -i art.jpg --start 62 --length 40 \
    --style mirror --color "#ff2d4a" --color2 "#ffffff"

# слайдшоу на замедленной скорости, вертикальное, под Shorts
python -m musicvideo track.mp3 -i pics/ -p shorts --speed 0.85 --reverb 0.5

# взять пресет за основу и доправить остальное руками
python -m musicvideo dump-config track.mp3 -p retro --dump-to retro.json
python -m musicvideo track.mp3 -c retro.json
```
