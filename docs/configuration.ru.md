# Справочник по конфигурации

[English](configuration.md) · **Русский**

[← к README](../README.ru.md) · [CLI](cli.ru.md) · [Python API](api.ru.md)

Любое значение ниже можно задать в JSON-файле, переданном через `-c`. Рабочий
пример лежит в `config.example.json`; чтобы получить файл, заполненный всеми
текущими значениями:

```bash
python -m musicvideo dump-config track.mp3 -p aesthetic --dump-to my.json
```

## Как сливаются настройки

Четыре слоя, каждый перекрывает предыдущий:

```
умолчания  →  пресет  →  файл конфига (-c)  →  флаги CLI
```

Слияние рекурсивное и по полям. Частичная секция меняет только те поля,
которые в ней названы:

```json
{ "visualizer": { "color": "#ff0000" } }
```

сохраняет `style`, `radius`, `amplitude` и всё остальное из пресета. Это
полезное поведение, и оно закреплено тестами: частичная секция никогда не
заменяет секцию целиком.

Неизвестное поле — ошибка, а не молчаливое игнорирование:

```
Ошибка конфигурации: visualizer: неизвестные параметры ['colour'].
  Допустимые: amplitude, baseline, cap, center, color, color2, ...
```

После `Допустимые:` перечислены все поля, которые принимает секция. Сообщения
печатаются на том языке, на который настроен интерфейс, — см.
[Язык](cli.ru.md#язык).

Если `preset` задан и в файле, и в командной строке, побеждает командная строка.

## Единицы и координаты

- **Позиции** (`position`, `center`, `baseline`) — доли кадра: `[0.5, 0.44]`
  это центр по горизонтали и 44 % высоты сверху.
- **Размеры** (`size`, `radius`, `amplitude`, `thickness`, кегли шрифтов) —
  пиксели для кадра, у которого *короткая сторона* равна 1080; затем они
  пересчитываются под реальный кадр. Настройка, которая хорошо смотрится
  на 1920×1080, так же выглядит на 1080×1920 и на 1280×720.
- **Цвета** принимают `#rgb`, `#rgba`, `#rrggbb`, `#rrggbbaa` и названия цветов
  PIL. Альфа-канал работает везде: `"#ffffffb0"` — полупрозрачный белый.

## Верхний уровень

| Поле | Тип | Умолчание | Смысл |
|------|-----|-----------|-------|
| `audio_file` | строка | `""` | Исходный трек. Задаётся и позиционным аргументом CLI. |
| `output` | строка | `"output/video.mp4"` | Куда положить результат. Родительские папки создаются. |
| `preset` | строка \| null | `null` | Пресет, поверх которого всё собирается. |
| `preview` | число \| null | `null` | Отрендерить только первые N секунд. |
| `workers` | int | `0` | Процессы рендера; `0` — автоматически (ядра − 1, и не меньше ~40 кадров на каждый). |

## `video`

| Поле | Тип | Умолчание | Смысл |
|------|-----|-----------|-------|
| `width` | int | `1920` | Ширина кадра. Должна быть чётной. |
| `height` | int | `1080` | Высота кадра. Должна быть чётной. |
| `fps` | int | `30` | Кадров в секунду. |
| `crf` | int | `21` | Качество x264, 0–51; меньше — лучше и крупнее. |
| `preset` | строка | `"medium"` | Пресет скорости x264: `ultrafast` … `veryslow`. |
| `pixel_format` | строка | `"yuv420p"` | Формат пикселей на выходе. `yuv420p` ожидают плееры и площадки. |
| `audio_bitrate` | строка | `"320k"` | Битрейт AAC для звука в контейнере. |

Требование чётных сторон идёт от `yuv420p`: его цветовые плоскости вдвое
меньше по разрешению, поэтому нечётные ширина или высота не кодируются.
Проверка конфигурации отклоняет их сразу, а не даёт ffmpeg упасть через
несколько минут работы.

## `audio`

| Поле | Тип | Умолчание | Смысл |
|------|-----|-----------|-------|
| `speed` | float | `1.0` | `0.85` = slowed, `1.15` = sped up. Высота тона меняется вместе с темпом — в этом и состоит эффект «slowed». |
| `reverb` | float | `0.0` | Количество реверберации, 0–1. |
| `reverb_room` | int | `480` | Длина хвоста реверберации, мс. |
| `bass_boost` | float | `0.0` | Подъём низкой полки на 110 Гц, дБ. |
| `normalize` | bool | `true` | Нормализация громкости (`loudnorm`, I = −14 LUFS). |
| `fade_in` | float | `1.0` | Нарастание звука, с. |
| `fade_out` | float | `3.0` | Затухание звука, с. |
| `start` | float | `0.0` | Пропустить столько секунд исходника. |
| `duration` | float \| null | `null` | Взять только столько секунд исходника. |

`start` и `duration` применяются к *исходнику*, до `speed`. При `speed: 0.85`
отрезок `duration` в 40 секунд превращается примерно в 47 секунд видео.

Цепочка фильтров, которую в итоге выполняет ffmpeg, по порядку: скорость
(`asetrate` + `aresample`) → низкая полка → реверберация (две каскадные
ступени `aecho`) → `loudnorm` → фейды → финальный лимитер на −0,26 dBFS.
Реверберация собрана из эхо, а не из импульсной характеристики, чтобы
не требовался внешний IR-файл.

## `analysis`

Как спектр превращается в числа, которые рисует визуализатор. Умолчания
подобраны под музыку; трогать их стоит, только если полосы кажутся слишком
дёрганными или слишком вялыми.

| Поле | Тип | Умолчание | Смысл |
|------|-----|-----------|-------|
| `n_bands` | int | `64` | Число частотных полос. |
| `n_fft` | int | `4096` | Размер окна FFT. Больше — лучше по частоте, размытее по времени. |
| `fmin` | float | `30.0` | Нижняя показываемая частота, Гц. |
| `fmax` | float | `14000.0` | Верхняя показываемая частота, Гц. |
| `db_range` | float | `62.0` | Сколько дБ укладывается в диапазон 0–1. |
| `attack` | float | `0.55` | Скорость нарастания полосы, 0–1. Больше — резче. |
| `decay` | float | `0.16` | Скорость спада полосы, 0–1. Меньше — длиннее шлейфы. |
| `band_blur` | float | `0.8` | Сглаживание по соседним полосам. |
| `tilt` | float | `0.55` | Подъём высоких частот, 0–1, чтобы правая половина спектра не замирала. |

Полосы расставлены геометрически между `fmin` и `fmax` (то есть равномерно
по октавам — так устроен слух), а огибающая асимметрична: быстро вверх,
медленно вниз. На тишине шкала упирается в абсолютный порог, поэтому
визуализатор гаснет, а не растягивается на шумовую подложку.

## `background`

| Поле | Тип | Умолчание | Смысл |
|------|-----|-----------|-------|
| `image` | строка \| список \| null | `null` | Картинка, папка или список путей. |
| `fallback` | строка | `"gradient"` | Что рисовать без картинки: `gradient` (диагональная растяжка), `noise` (она же плюс мягкие пятна) или `solid` (первый цвет заливкой). |
| `colors` | список | `["#1b1033", "#07070c"]` | Цвета процедурного фона. |
| `blur` | float | `18.0` | Радиус размытия в px. |
| `brightness` | float | `0.55` | Затемнение, 0–1. |
| `saturation` | float | `1.05` | Множитель насыщенности. |
| `zoom` | float | `1.12` | Зум Кена Бёрнса: во сколько раз увеличится за весь ролик. |
| `pan` | список | `[0.0, 0.0]` | Панорамирование `[dx, dy]` в долях кадра за весь ролик. |
| `beat_zoom` | float | `0.018` | Добавка к масштабу на басу, в долях. |
| `shake` | float | `3.0` | Тряска кадра на басу, px. |
| `crossfade` | float | `1.5` | Длина кроссфейда между картинками, с. |
| `grain` | float | `0.035` | Плёночное зерно, 0–1. Главный фактор размера файла. |
| `grain_size` | int | `2` | Крупность зерна в px. `1` — попиксельный шум: несжимаемый и огромный. |

При нескольких картинках ролик делится между ними поровну, а каждый переход —
растворение длиной `crossfade`.

### Про `grain`

Зерно случайно, поэтому кодек не может предсказать его между кадрами и тратит
биты каждый раз заново. Замеры на демо-ролике в 1080p/30, CRF 21:

| Настройка | Битрейт | Трёхминутный трек |
|-----------|--------:|------------------:|
| `grain: 0` | 1.9 Мбит/с | ~43 МБ |
| `grain_size: 2` (умолчание) | 24 Мбит/с | ~540 МБ |
| `grain_size: 1` | 63 Мбит/с | ~1.4 ГБ |

Генерация шума в уменьшенном масштабе с последующим растягиванием и больше
похожа на плёнку, и стоит примерно втрое дешевле.

## `visualizer`

| Поле | Тип | Умолчание | Смысл |
|------|-----|-----------|-------|
| `enabled` | bool | `true` | Рисовать ли визуализатор вообще. |
| `style` | строка | `"circle"` | `circle`, `bars`, `mirror`, `wave`, `ring`, `dots`. |
| `color` | строка | `"#ffffff"` | Основной цвет. |
| `color2` | строка \| null | `"#8b5cf6"` | Второй цвет; полосы окрашиваются градиентом между ними. `null` — однотонно. |
| `opacity` | float | `0.92` | Общая непрозрачность. |
| `glow` | float | `16.0` | Радиус свечения, px. `0` — выключено (и заметно быстрее). |
| `glow_strength` | float | `0.85` | Интенсивность свечения. |
| `amplitude` | float | `190.0` | Высота полосы на полном уровне, px. |
| `thickness` | float | `7.0` | Толщина штриха или бара. |
| `gap` | float | `5.0` | Зазор между барами. |
| `cap` | строка | `"round"` | Форма торца бара: `round` или `flat`. |
| `range` | строка | `"full"` | Какие частоты показывать: `full`, `bass`, `mid`, `high`. |

Радиальные стили (`circle`, `ring`, `dots`):

| Поле | Тип | Умолчание | Смысл |
|------|-----|-----------|-------|
| `radius` | float | `250.0` | Радиус кольца, px. |
| `center` | список | `[0.5, 0.44]` | Центр кольца, в долях кадра. |
| `start_angle` | float | `-90.0` | Где находится нулевая полоса; `-90` — сверху. |
| `mirror` | bool | `true` | Зеркалить спектр по кругу. |
| `inward` | bool | `false` | Рисовать лучи внутрь, а не наружу. |

Линейные стили (`bars`, `mirror`, `wave`):

| Поле | Тип | Умолчание | Смысл |
|------|-----|-----------|-------|
| `baseline` | float | `0.88` | Высота базовой линии, в долях кадра. |

### Стили одним взглядом

| Стиль | Как выглядит |
|-------|--------------|
| `circle` | Лучи, расходящиеся от кольца, — классический вид «audio edit». |
| `bars` | Вертикальные бары, стоящие на базовой линии. |
| `mirror` | Бары, растущие от базовой линии вверх *и* вниз. |
| `wave` | Одна плавная линия, колеблющаяся вдоль базовой. |
| `ring` | Тонкое замкнутое кольцо, деформируемое спектром. |
| `dots` | Точки на кольце, уходящие наружу вместе с уровнем. |

### Чтобы визуализатор не задевал обложку

Радиальный визуализатор со слишком маленьким радиусом прорежет обложку.
Правило:

- круглая обложка: `radius > cover.size / 2`
- квадратная обложка: `radius > cover.size * 0.71`

А снаружи `radius + amplitude` должен укладываться в половину короткой стороны
кадра — 540 px и для 1920×1080, и для 1080×1920.

## `text`

Содержит `title`, `artist` и `extra` — список произвольного числа
дополнительных подписей с теми же полями.

| Поле | Тип | Умолчание | Смысл |
|------|-----|-----------|-------|
| `text` | строка | `""` | Текст подписи. Пустой — не рисуется. |
| `font` | строка \| null | `null` | Имя файла шрифта без расширения. |
| `size` | int | `54` | Кегль, px. |
| `color` | строка | `"#ffffff"` | Цвет текста. |
| `opacity` | float | `1.0` | Непрозрачность. |
| `position` | список | `[0.5, 0.72]` | Точка привязки, в долях кадра. По вертикали это середина текста. |
| `align` | строка | `"center"` | `left`, `center` или `right` — какой стороной текст прижат к точке. |
| `letter_spacing` | float | `0.0` | Дополнительный интервал между буквами, px. |
| `uppercase` | bool | `false` | Принудительно верхний регистр. |
| `shadow` | float | `18.0` | Радиус размытия тени. |
| `shadow_color` | строка | `"#000000b0"` | Цвет тени. |
| `fade_in` | float | `0.8` | Длительность появления, с. |
| `delay` | float | `0.3` | Задержка до начала появления, с. |

У `title` и `artist` свои умолчания (крупный заголовок на `[0.5, 0.70]`;
меньший, полупрозрачный, в верхнем регистре исполнитель на `[0.5, 0.762]`).
Полоса прогресса появляется вместе с заголовком.

Дополнительная подпись:

```json
{ "text": { "extra": [
  { "text": "slowed + reverb", "size": 26, "position": [0.5, 0.93],
    "color": "#ffffff80", "uppercase": true, "letter_spacing": 4.0 }
] } }
```

### Шрифты

Шрифты ищутся сначала в `assets/fonts`, затем в системных каталогах. Указывать
нужно имя файла, а не семейства: `"Montserrat-SemiBold"` найдёт
`assets/fonts/Montserrat-SemiBold.ttf`. Если `font` не задан, берётся первый
доступный из Montserrat, Poppins, Inter, Roboto, Open Sans и системных
умолчаний платформы.

## `overlay`

Полнокадровые эффекты, применяемые последними, к уже собранному кадру.

| Поле | Тип | Умолчание | Смысл |
|------|-----|-----------|-------|
| `vignette` | float | `0.55` | Сила виньетки, 0–1. |
| `vignette_size` | float | `0.78` | Насколько далеко от центра начинается виньетка. |
| `scanlines` | float | `0.0` | Сила горизонтальных полос, 0–1. Вид VHS. |
| `letterbox` | float | `0.0` | Высота чёрных полос в долях кадра; `0.12` — «кино». |
| `tint` | строка \| null | `null` | Цвет тонировки, например `"#ff5a3c"`. |
| `tint_strength` | float | `0.0` | Сила тонировки, 0–1. Требует заданного `tint`. |
| `beat_flash` | float | `0.0` | Засветка кадра на удар. |
| `fade_in` | float | `1.2` | Появление из чёрного, с. |
| `fade_out` | float | `2.5` | Уход в чёрное, с. |

Порядок важен и фиксирован: тонировка → виньетка → засветка → полосы → зерно →
фейд → letterbox. Чёрные полосы идут последними, чтобы остаться чистыми
и без зерна.

## Полный пример

```json
{
  "audio_file": "track.mp3",
  "output": "output/video.mp4",
  "preset": "aesthetic",

  "video":   { "width": 1920, "height": 1080, "fps": 30, "crf": 21 },
  "audio":   { "speed": 0.88, "reverb": 0.35, "bass_boost": 2.0 },

  "background": {
    "image": "art.jpg",
    "blur": 22.0, "brightness": 0.5, "zoom": 1.14, "grain": 0.04
  },

  "cover": { "shape": "circle", "size": 440, "position": [0.5, 0.44] },

  "visualizer": {
    "style": "circle", "radius": 262.0, "amplitude": 150.0,
    "color": "#ffffff", "color2": "#a78bfa", "glow": 18.0
  },

  "text": {
    "title":  { "text": "Way Down We Go", "size": 64 },
    "artist": { "text": "Kaleo" }
  },

  "overlay": { "vignette": 0.6, "beat_flash": 0.05 }
}
```

```bash
python -m musicvideo track.mp3 -c этот-файл.json
```
